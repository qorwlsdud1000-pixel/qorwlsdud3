# EcoScan 컴퓨터비전2 과제 발표 가이드

## 프로젝트 소개
- **서비스명**: EcoScan — AI 재활용품 분류 서비스
- **문제 정의**: 재활용품 종류가 헷갈리는 경우, 이미지 분석과 배출 방법 가이드를 함께 제공
- **사용자 흐름**: 사진 업로드 → AI 분석 클릭 → 추정 재질/상위 3개 후보 → 분리배출 방법 → 분석 기록

## 기술 스택 및 구조
- 프런트엔드: HTML/CSS/JavaScript, Vite
- 이미지 분류: Transformers.js + CLIP (`Xenova/clip-vit-base-patch32`)
- 추론: 브라우저 내 제로샷 이미지-문장 유사도 계산
- 상태 저장: localStorage (이미지 자체는 저장하지 않음)
- 배포: GitHub + Vercel

## PPT 추천 구성(8장)
1. 표지: EcoScan — 사진 한 장으로 시작하는 올바른 분리배출
2. 주제 선정 이유와 해결하려는 문제
3. 서비스 주요 기능 / 사용 흐름
4. 개발 환경, 기술 스택과 시스템 구성도
5. 바이브 코딩 프롬프트와 개발 과정 (실제 사용 대화/스크린샷 삽입)
6. 핵심 기능 구현 — 이미지 입력, AI 분류, 결과 가이드
7. 실시간 시연 — 사진 2~3장 업로드 및 결과 비교
8. 한계, 개선 계획, GitHub/Vercel 주소

## 발표용 설명 예시
“저희는 이미지 한 장으로 재활용품의 종류를 추정하고 배출 방법을 안내하는 EcoScan을 개발했습니다. 브라우저에서 CLIP이라는 이미지-텍스트 모델을 실행해 10개의 후보 범주를 비교합니다. 사용자는 촬영한 사진을 올리고 결과와 안내를 확인할 수 있습니다. 다만 이 점수는 정답 확률이 아니며, 오염 여부나 지역마다 다른 배출 규칙은 사진만으로 확정하기 어려워 안내 문구를 함께 표시했습니다.”

## 바이브 코딩 설명
다음은 프로젝트 설계 의도를 설명하는 **프롬프트 예시**입니다. 실제로 대화에 사용한 문장만 사용했다고 발표하세요.

- “컴퓨터비전 과제로 쓸 반응형 재활용품 이미지 분류 웹앱을 만들어 줘.”
- “실제 브라우저 AI 모델을 사용하고 임의 결과는 출력하지 마.”
- “파일 드래그앤드롭, 10개 재질 분류, 상위 3개 점수와 배출 가이드를 추가해 줘.”
- “GitHub와 Vercel에 배포할 수 있게 Vite 기반으로 정리해 줘.”
- “분류 확률을 과장하지 않고 불확실성을 안내해 줘.”

## 한계 및 향후 개선
- 일반 범용 CLIP 모델은 한국 분리배출 특화 모델이 아니어서 오분류 가능
- 다양한 배경이나 복합재질을 자동 판별하기 어려움
- 실험 데이터셋을 구축해 클래스별 정밀도·재현율을 측정하고 파인튜닝할 수 있음
- 지자체별 배출 지침 API와 연동 가능

**주의:** 본 안내 문서는 PPT 파일 자체가 아니라 발표를 구성하는 자료입니다. 실제 PPT 제작 시 화면 캡처와 본인이 수행한 과정을 추가하세요.
